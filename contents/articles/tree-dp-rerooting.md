# 树形 DP 与换根 DP 入门

**发布日期：** 2025-11-08  
**标签：** 树形DP、换根DP、动态规划

树形 DP 的核心在于：**利用树的递归结构，把一个点的答案拆成若干个子树答案合并**。  
而换根 DP 则是在此基础上，进一步把“根外的信息”也传给子节点。

## 一、树形 DP 在做什么

一般会先任选一个根，比如 `1`，把无根树转成有根树。

然后思考：

- 每个节点需要从子树里获得什么信息？
- 父节点如何由多个孩子的信息合并得到答案？

常见状态：

- 子树大小
- 子树和
- 子树内最大值
- 选 / 不选当前点的最优值

## 二、一个最基础的例子：树上最大独立集

设：

- `dp[u][0]` 表示不选 `u` 时，`u` 子树的最优值
- `dp[u][1]` 表示选 `u` 时，`u` 子树的最优值

转移：

```text
dp[u][1] += dp[v][0]
dp[u][0] += max(dp[v][0], dp[v][1])
```

这个模型是树形 DP 的经典入门题。

## 三、换根 DP 为什么要出现

普通树形 DP 只能求“以某个固定根为视角”的答案。  
但很多题要问：

- 以每个点为根时的答案
- 每个点到所有点距离和
- 每个点作为根时的某个最优值

这时只做一遍自底向上的 DFS 不够，因为每个点还会受到“根外部分”的影响。

## 四、换根 DP 的典型思路

通常分两遍 DFS：

### 第一遍 DFS

先求子树内部信息，例如：

- `sz[u]`：子树大小
- `down[u]`：子树内答案

### 第二遍 DFS

把父亲方向的信息传给儿子，得到“整棵树视角”下的答案。

这就是所谓的换根。

## 五、经典例子：每个点到所有点距离和

第一遍 DFS 求：

- `sz[u]`：子树大小
- `dp[u]`：`u` 子树内所有点到 `u` 的距离和

```cpp
void dfs1(int u, int fa) {
    sz[u] = 1;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        dp[u] += dp[v] + sz[v];
    }
}
```

第二遍 DFS 设 `ans[u]` 为 `u` 到全树所有点距离和：

```cpp
void dfs2(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        ans[v] = ans[u] - sz[v] + (n - sz[v]);
        dfs2(v, u);
    }
}
```

为什么这个式子对？

- 根从 `u` 换到 `v` 后，`v` 子树里的点离根都少 1
- 其余点离根都多 1

所以：

```text
ans[v] = ans[u] - sz[v] + (n - sz[v])
```

## 六、换根 DP 的本质

换根 DP 的关键不是“背公式”，而是弄清楚：

> 当根从父亲移动到儿子时，哪些点的贡献减少了，哪些点的贡献增加了？

很多题都可以从这个角度推转移。

## 七、树形 DP 常见题型

- 选点类 DP
- 子树合并
- 树上背包
- 距离统计
- 每个点作为根时的答案

## 八、容易写错的地方

### 1. 父节点没跳过

DFS 时忘记 `if (v == fa) continue;` 是最基础 bug。

### 2. 状态含义不清

如果 `dp[u]` 的定义模糊，后面转移会越来越乱。

### 3. 换根公式只记结论不理解

最好从“贡献变化”推一遍，不要机械背。

## 九、做题建议

拿到树形 DP 题时，我通常先问：

1. 只要子树信息，还是需要全树信息？
2. 每个点的答案是否依赖父亲方向？
3. 能不能先求子树，再做第二遍转移？

如果第二问答案是“会依赖”，那就很可能要换根。

## 十、结语

树形 DP 和换根 DP 是树论里非常重要的一部分。只要把“子树内信息”和“根外信息”分清楚，很多看似复杂的树题都会变成两遍 DFS 的结构化问题。
