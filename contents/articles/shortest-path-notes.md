# 最短路算法选型：BFS、Dijkstra、Bellman-Ford、Floyd

**发布日期：** 2025-03-26  
**标签：** 图论、最短路、算法选型

最短路题最容易让人混乱的地方，不是不会写某个算法，而是**不知道该选哪个算法**。这篇笔记重点不是罗列模板，而是梳理算法选型逻辑。

## 一、先看边权

判断最短路算法时，第一步先看边权：

- 全部边权相同：BFS
- 边权只有 `0/1`：0-1 BFS
- 边权非负：Dijkstra
- 存在负边：Bellman-Ford / SPFA（慎用）/ Johnson
- 多源点且点数不大：Floyd

这一步往往已经能排除大半错误选项。

## 二、几种算法的适用场景

## 1. BFS

适合无权图或每条边权都相同的图。

复杂度：

```text
O(n + m)
```

特点：

- 最短路层数天然由 BFS 层次决定
- 实现最简单

## 2. 0-1 BFS

当边权只有 `0` 或 `1` 时，可用双端队列维护。

规则：

- 走权值 0 的边，压到队首
- 走权值 1 的边，压到队尾

复杂度接近线性，常数比 Dijkstra 更好。

## 3. Dijkstra

适合**所有边权非负**的单源最短路。

堆优化模板：

```cpp
priority_queue<pair<long long,int>,
               vector<pair<long long,int>>,
               greater<pair<long long,int>>> pq;

dist[s] = 0;
pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top();
    pq.pop();
    if (d != dist[u]) continue;
    for (auto [v, w] : g[u]) {
        if (dist[v] > dist[u] + w) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
    }
}
```

复杂度：

```text
O((n + m) log n)
```

## 4. Bellman-Ford

适合存在负边的情况，也能判断负环。

核心思想：

- 做 `n - 1` 轮松弛
- 如果第 `n` 轮还能松弛，说明有负环

复杂度：

```text
O(nm)
```

一般只在：

- 点边规模较小
- 明确需要处理负边
- 需要判断负环

时使用。

## 5. Floyd

适合多源最短路，尤其是：

- 点数较小（比如 `n <= 400` 左右）
- 需要任意两点最短路

转移公式：

```text
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

复杂度：

```text
O(n^3)
```

## 三、最短路题的常见问法

### 1. 单源最短路

从一个起点到所有点：优先考虑 Dijkstra / BFS。

### 2. 多源最短路

可以：

- 建超级源点
- 多个源点一起入队
- 或直接 Floyd

### 3. 最短路条数

在松弛时同时维护方案数：

- 更短就覆盖
- 相等就累加

### 4. 次短路 / 限制条件最短路

往往需要：

- 分层图
- 状态扩展
- DP + 最短路

## 四、常见坑

### 1. Dijkstra 不能处理负边

这是最经典的错误，没有之一。

### 2. 邻接矩阵和邻接表别乱选

- 稀疏图：邻接表
- 稠密图：邻接矩阵也可接受

### 3. 初始化无穷大要安全

一般写：

```cpp
const long long INF = 4e18;
```

不要让加法溢出。

### 4. 堆优化 Dijkstra 要判“过期状态”

```cpp
if (d != dist[u]) continue;
```

这一句非常关键。

## 五、一张简单的选型表

| 情况 | 推荐算法 |
|------|----------|
| 无权图 | BFS |
| 边权只有 0/1 | 0-1 BFS |
| 非负边权单源 | Dijkstra |
| 有负边单源 | Bellman-Ford |
| 多源、点数小 | Floyd |
| 需要判负环 | Bellman-Ford |

## 六、做题流程建议

我通常这样判断：

1. 问单源还是多源？
2. 有没有负边？
3. 图稀疏还是稠密？
4. 只求距离，还是还要路径条数 / 负环 / 次短路？

只要这四步走清楚，算法选型一般不会偏。

## 七、结语

最短路题真正重要的是“建图 + 选型”，不是死背模板。  
把每种算法的使用边界记清楚，很多图论题都会变简单。
