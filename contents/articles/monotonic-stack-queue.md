# 单调栈与单调队列题型整理

**发布日期：** 2025-08-30  
**标签：** 数据结构、单调栈、单调队列

单调栈和单调队列的本质都是：**维护一段“有顺序的候选答案集合”**，把不可能再成为答案的元素及时弹掉。

掌握这类结构，很多“最近更大 / 最近更小 / 滑动窗口最值 / 区间贡献”题都会明显简单。

## 一、单调栈解决什么问题

常见场景：

- 每个位置左边第一个更大 / 更小元素
- 每个位置右边第一个更大 / 更小元素
- 直方图最大矩形
- 子数组最小值 / 最大值贡献统计

## 二、单调栈的核心套路

以“求右边第一个严格更大元素”为例：

```cpp
stack<int> st;
for (int i = 1; i <= n; i++) {
    while (!st.empty() && a[st.top()] < a[i]) {
        ans[st.top()] = i;
        st.pop();
    }
    st.push(i);
}
```

理解重点：

- 栈里存的是“还没找到答案的位置”
- 一旦当前元素更优，就可以把前面一些位置的答案结算掉

## 三、常见四种写法

你需要区分：

- 左边还是右边
- 更大还是更小
- 严格还是不严格

例如处理重复值时：

- 如果题目要求“严格更大”，就用 `<`
- 如果题目要求“更大或相等”，就用 `<=`

这一点会直接影响是否重算或漏算。

## 四、单调队列解决什么问题

最经典的是滑动窗口最值。

例：维护长度为 `k` 的窗口最大值。

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    while (!q.empty() && q.front() <= i - k) q.pop_front();
    if (i >= k) ans.push_back(a[q.front()]);
}
```

队列里维护的是“当前窗口中还可能成为最值的下标”。

## 五、为什么能弹掉元素

核心理由是“支配关系”：

如果一个新元素比旧元素更优，而且位置还更靠后，那么旧元素以后就不可能成为答案。

例如滑动窗口最大值中：

- 新元素更大
- 新元素出现得更晚

那旧元素不管在当前窗口还是未来窗口，都没有优势。

## 六、经典题型

### 1. 最近更大元素

单调栈模板题。

### 2. 直方图最大矩形

求每个柱子向左、向右第一个比它小的位置，再算它作为最低柱子的最大宽度。

### 3. 滑动窗口最大值 / 最小值

单调队列模板题。

### 4. 子数组最小值之和

本质上是贡献法 + 单调栈。

要计算：

- 当前元素作为最小值能覆盖多少左端点
- 能覆盖多少右端点

再把贡献乘起来。

## 七、单调结构里最容易错的地方

### 1. 严格和不严格条件

处理重复值时，左右两边常常要一边严格、一边不严格，防止重复统计。

### 2. 下标出窗口时机

单调队列里一定先处理队尾单调性，再处理队首是否过期，或者根据你的实现保持一致。

### 3. 栈里存值还是存下标

大多数题都应该存下标，因为：

- 要比较位置
- 要算距离
- 要区分重复值

## 八、做题识别信号

如果题目问：

- 某个元素最近的更大 / 更小位置
- 每个窗口的最大值 / 最小值
- 每个元素对若干区间的贡献

那就该想到单调栈或单调队列。

## 九、结语

单调结构的关键不是“模板”，而是理解为什么某些元素可以安全删除。只要看懂“后来的更优元素会淘汰先前劣质候选”，很多题目都会自然落到单调栈/队列上。
