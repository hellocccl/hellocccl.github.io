# 树状数组入门到经典模型

**发布日期：** 2024-09-21  
**标签：** 数据结构、树状数组、前缀和

树状数组（Fenwick Tree）是一个非常适合维护“前缀信息”的数据结构。它的常见用途是：

- 单点修改
- 前缀和查询
- 区间和查询
- 逆序对统计
- 离散化后的频次维护

相比线段树，树状数组代码更短、常数更小，适合很多中等复杂度题目。

## 一、核心思想

树状数组利用二进制最低位 `lowbit(x)` 来管理一段前缀信息：

```cpp
int lowbit(int x) {
    return x & -x;
}
```

`tree[x]` 维护的是一段长度为 `lowbit(x)` 的区间和。

## 二、基础模板

### 1. 单点加，前缀和查询

```cpp
struct BIT {
    int n;
    vector<long long> tree;

    BIT(int n = 0) : n(n), tree(n + 1, 0) {}

    void add(int x, long long v) {
        for (int i = x; i <= n; i += i & -i) {
            tree[i] += v;
        }
    }

    long long sum(int x) {
        long long res = 0;
        for (int i = x; i > 0; i -= i & -i) {
            res += tree[i];
        }
        return res;
    }

    long long query(int l, int r) {
        return sum(r) - sum(l - 1);
    }
};
```

复杂度：

- 修改 `O(log n)`
- 查询 `O(log n)`

## 三、为什么它能跑对

可以把 `sum(x)` 理解成：不断跳到它的“上一个管理块”，直到走到 0。  
而 `add(x, v)` 则是：把所有包含位置 `x` 的管理块都更新到。

这正是 `lowbit` 的作用。

## 四、最常见的应用

### 1. 动态维护前缀和

这是最基础的场景。

### 2. 逆序对统计

做法：

1. 先离散化。
2. 从右往左扫描。
3. 查询当前值之前出现了多少更小元素。

```cpp
long long inv = 0;
for (int i = n; i >= 1; i--) {
    inv += bit.sum(rank[a[i]] - 1);
    bit.add(rank[a[i]], 1);
}
```

### 3. 维护频次并求第 k 小

如果树状数组维护的是值域频次，还可以结合二进制跳法求第 `k` 小。

### 4. 离散化 + 扫描

很多“值域很大，但相对顺序重要”的题，本质都是：

- 离散化
- 树状数组维护出现次数 / 权值和

## 五、树状数组的扩展

### 1. 区间加，单点查

对差分数组建树状数组即可。

如果要给 `[l, r]` 加 `v`：

```cpp
bit.add(l, v);
bit.add(r + 1, -v);
```

查询单点 `x` 的值时，直接求前缀和。

### 2. 区间加，区间和查

需要两个树状数组，维护：

- `B1`
- `B2`

公式：

```text
prefix(x) = (x + 1) * sum(B1, x) - sum(B2, x)
```

这是一个很经典的扩展，比赛里出现频率不低。

## 六、树状数组和线段树怎么选

优先选树状数组的情况：

- 只需要前缀和/区间和
- 修改方式比较规整
- 需要更小常数

优先选线段树的情况：

- 需要维护最值
- 需要复杂区间信息
- 需要懒标记

## 七、常见坑

### 1. 下标必须从 1 开始

树状数组天然依赖 `lowbit`，所以一般不直接用 0 下标。

### 2. 离散化别漏重

如果题目数据范围大，一定先离散化，不然空间开不下。

### 3. `long long`

频次题可以用 `int`，但权值和、逆序对数量经常必须用 `long long`。

## 八、一个做题判断信号

如果题目满足下面任意一条，就要想到树状数组：

- 动态维护前缀和
- 维护一个“排名 / 频次”
- 查询某个值左边或右边有多少个元素
- 统计逆序对 / 顺序对

## 九、结语

树状数组不是很“万能”，但在它擅长的范围内非常强。  
真正要掌握的不是模板本身，而是看到“前缀信息维护”和“频次统计”时，能第一时间联想到它。
