# 并查集常见套路总结

**发布日期：** 2025-01-09  
**标签：** 数据结构、并查集、图论

并查集（Disjoint Set Union, DSU）是维护集合合并与连通性的经典结构。它的核心操作很少：

- `find(x)`：找 `x` 所在集合的代表元
- `merge(x, y)`：合并两个集合

但它的变形和应用场景非常广。

## 一、基础模板

```cpp
struct DSU {
    vector<int> fa, sz;

    DSU(int n = 0) {
        fa.resize(n + 1);
        sz.assign(n + 1, 1);
        iota(fa.begin(), fa.end(), 0);
    }

    int find(int x) {
        if (fa[x] == x) return x;
        return fa[x] = find(fa[x]);
    }

    bool merge(int x, int y) {
        x = find(x), y = find(y);
        if (x == y) return false;
        if (sz[x] < sz[y]) swap(x, y);
        fa[y] = x;
        sz[x] += sz[y];
        return true;
    }
};
```

两大优化：

- 路径压缩
- 按大小 / 按秩合并

## 二、并查集适合什么题

典型信号：

- 动态连通性
- 若干点边加入后问是否联通
- 连通块个数
- 最小生成树（Kruskal）
- 离线处理关系约束

## 三、最经典的几个应用

### 1. 判断图是否连通

遍历所有边，把端点合并。最后看所有点是否属于同一集合。

### 2. 维护连通块个数

初始每个点一个连通块。每次成功合并，答案减一。

### 3. Kruskal 最小生成树

把边按权值排序，依次尝试加入。如果两个端点不连通，就选这条边并合并。

这是并查集最典型的图论应用。

## 四、扩展一：维护集合大小

很多题会问：

- 某个点所在连通块大小
- 当前最大连通块大小

这时 `sz[find(x)]` 就很有用。

## 五、扩展二：带权并查集

带权并查集适合维护“点到根的某种关系”，例如：

- 到根的距离
- 奇偶性
- 模 3 关系

以维护奇偶性为例，常用于“二分图判定”类问题。

需要额外维护：

```cpp
dist[x] = x 到 fa[x] 的关系
```

在路径压缩时同步更新关系值。

## 六、扩展三：离线倒序处理

有些删边题不能在线做，但可以：

1. 把删除操作改成倒序加边
2. 从后往前处理
3. 用并查集合并

这是并查集非常常见的离线技巧。

## 七、为什么按大小合并有用

如果总是把小集合挂到大集合上，树高会更稳定。  
虽然单靠路径压缩就已经很强，但按大小合并几乎是零成本优化。

## 八、容易写错的地方

### 1. 合并前忘记先 `find`

很多 bug 都是因为直接写：

```cpp
fa[x] = y;
```

正确做法应该是合并代表元。

### 2. 带权并查集路径压缩时没更新关系

这类错误表面不明显，但答案会完全错。

### 3. 集合大小更新错对象

按大小合并后，要把小集合并到大集合根上，再更新大根的 `sz`。

## 九、做题时怎么判断“该用并查集”

如果题目只关心：

- 在不在同一个集合
- 合并后整体信息
- 连通块结构

那就优先考虑并查集。

如果题目需要路径信息、树上查询、动态删除的在线强保证，就不一定适合。

## 十、结语

并查集本身很短，但价值很高。它的重点不是模板，而是识别题目里“集合合并”和“连通性维护”的结构。一旦看出这一层，很多题会从复杂图论题一下变成模板题。
