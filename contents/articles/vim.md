# Vim 编辑器使用指南

**发布日期：** 2024-01-15  
**标签：** 编辑器、Vim、开发工具

## 简介

Vim 是一个强大的文本编辑器，虽然学习曲线陡峭，但一旦掌握，可以大大提高编辑效率。

## 基本操作

### 模式切换

- `i` - 进入插入模式
- `Esc` - 退出插入模式，回到普通模式
- `:` - 进入命令模式

### 基本移动

- `h` `j` `k` `l` - 左、下、上、右移动
- `w` - 移动到下一个单词开头
- `b` - 移动到上一个单词开头
- `0` - 移动到行首
- `$` - 移动到行尾

### 编辑操作

- `dd` - 删除当前行
- `yy` - 复制当前行
- `p` - 粘贴
- `u` - 撤销
- `Ctrl+r` - 重做

## 高级技巧

### 搜索和替换

```vim
/search_text    " 搜索
:%s/old/new/g   " 全局替换
```

### 多文件编辑

```vim
:split filename    " 水平分割窗口
:vsplit filename  " 垂直分割窗口
Ctrl+w w          " 切换窗口
```

## 总结

Vim 是一个功能强大的编辑器，需要时间和练习来掌握。建议从基本操作开始，逐步学习高级功能。
