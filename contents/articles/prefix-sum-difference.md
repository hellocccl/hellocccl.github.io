# 前缀和、差分与二维前缀和

**发布日期：** 2024-07-03  
**标签：** 前缀和、差分、基础算法

前缀和和差分是算法题里最基础、但也最常反复出现的一组工具。很多题如果直接暴力会超时，但一旦把“区间操作”改写成前缀和或差分，复杂度会一下子降下来。

## 一、一维前缀和

设原数组为 `a[1..n]`，定义：

```text
pre[i] = a[1] + a[2] + ... + a[i]
```

则区间和：

```text
sum(l, r) = pre[r] - pre[l - 1]
```

模板：

```cpp
vector<long long> pre(n + 1, 0);
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i - 1] + a[i];
}
```

适用场景：

- 多次询问区间和
- 区间平均值
- 固定长度子数组统计
- 子段和转化

## 二、前缀和的常见细节

### 1. 下标从 1 开始更顺手

这样 `pre[0] = 0`，区间公式统一，不容易在 `l = 1` 时特判。

### 2. 注意数据范围

如果 `n` 和元素值较大，前缀和一定优先用 `long long`。

### 3. 前缀和只能快速查询，不能直接处理区间加

如果题目频繁“给一段区间整体 +x”，应该考虑差分。

## 三、一维差分

差分数组定义为：

```text
diff[i] = a[i] - a[i - 1]
```

如果要对区间 `[l, r]` 全部加上 `v``，只需：

```text
diff[l] += v
diff[r + 1] -= v
```

最后做一次前缀和还原原数组。

模板：

```cpp
vector<long long> diff(n + 2, 0);

auto range_add = [&](int l, int r, long long v) {
    diff[l] += v;
    diff[r + 1] -= v;
};

for (int i = 1; i <= n; i++) {
    diff[i] += diff[i - 1];
    a[i] = diff[i];
}
```

适用场景：

- 多次区间加、最后统一输出
- 批量区间覆盖
- 扫描线思想的离散版本

## 四、前缀和与差分的关系

这两者其实互为“逆操作”：

- 前缀和：把局部信息累积成整体信息
- 差分：把区间修改压缩成端点修改

一个偏查询，一个偏修改。

## 五、二维前缀和

定义：

```text
pre[i][j] = (1,1) 到 (i,j) 的子矩阵元素和
```

转移公式：

```text
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]
```

查询子矩阵 `(x1,y1)` 到 `(x2,y2)` 的和：

```text
sum = pre[x2][y2]
    - pre[x1-1][y2]
    - pre[x2][y1-1]
    + pre[x1-1][y1-1]
```

模板：

```cpp
vector<vector<long long>> pre(n + 1, vector<long long>(m + 1, 0));
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        pre[i][j] = pre[i - 1][j] + pre[i][j - 1]
                  - pre[i - 1][j - 1] + a[i][j];
    }
}
```

## 六、二维差分

如果要给子矩阵 `(x1,y1)` 到 `(x2,y2)` 全部加上 `v`，可以在二维差分数组里做四次更新：

```text
diff[x1][y1] += v
diff[x2+1][y1] -= v
diff[x1][y2+1] -= v
diff[x2+1][y2+1] += v
```

最后通过二维前缀和还原。

这个技巧适合：

- 地图覆盖
- 矩阵批量加值
- 矩形统计

## 七、常见题型

### 1. 区间和查询

最标准的一维前缀和。

### 2. 固定长度子数组最大和

把每一段长度为 `k` 的区间和写成：

```text
pre[i] - pre[i-k]
```

### 3. 区间加后问最终数组

差分模板直接处理。

### 4. 二维矩阵求子矩形和

二维前缀和模板。

### 5. 扫描线离散计数

很多“覆盖多少次”的题，其实就是差分思想。

## 八、容易写错的地方

### 1. 忘记开到 `n + 2`

差分经常会访问 `r + 1`，保险起见多开一格。

### 2. 二维前缀和少减或少加

矩阵题最容易在容斥公式上写错，建议直接背熟：

```text
左上角加回来
```

### 3. 原数组和差分数组混用

如果是“在原数组基础上做差分”，要先正确初始化 `diff`。

## 九、一个实用模板

如果原数组已知，要先构造差分：

```cpp
for (int i = 1; i <= n; i++) {
    diff[i] = a[i] - a[i - 1];
}
```

这样后面再做多次区间加，最后统一还原。

## 十、结语

前缀和和差分的本质都是“把重复计算折叠掉”。它们并不花哨，但非常高频，尤其在基础题、数据结构题、图论中的离线统计题里都会反复出现。

如果你做题时发现：

- 一堆区间求和
- 一堆区间整体修改
- 一堆矩形加减和统计

那就应该第一时间想到前缀和 / 差分。
